Kid Apps

Two practice games. Each one saves its progress on this server, so it carries over between devices.

Pinehurst DM AcademyDungeon Master training: dice math, rules and encounter building. Chain ReactionTimes tables up to 12 × 12, earning screen time.

Put it on the iPad home screen

  1. Open the game in Safari.
  2. Tap the Share button, then Add to Home Screen.
  3. Open it from the new icon. It runs full screen and keeps working offline.

On a Mac, open it in Safari and choose File, then Add to Dock.

Using more than one device

Each device gets a save code, shown on the Parent or Grown-ups screen. Enter the same code on a second device to share one save.
